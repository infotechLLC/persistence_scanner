# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Do not open public issues for potential detection bypasses, collection weaknesses,
or rule evasion paths.

Report privately through GitHub Security Advisories for this repository.
Include:

- impacted version or commit SHA
- host artifact or sample entry that demonstrates the issue
- expected behavior vs observed behavior
- any known ATT&CK technique or persistence surface involved

We will triage reports as source-level defects in the detection or triage pipeline
and respond with remediation guidance or a fix plan.
